# Эмулятор трехадресного процессора гарвардской архитектуры

Практическая работа по дисциплине «Разработка программно-аппаратного обеспечения
информационных и автоматизированных систем» (РПАОИАС), **вариант 15**:

| Адресность | Архитектура | 1-е задание | 2-е задание |
|---|---|---|---|
| трехадресная | гарвардская | поиск максимума в массиве | свертка двух массивов, 6 элементов, целые числа без знака |

## Запуск

Нужен Python 3.8+ (tkinter входит в стандартную поставку Python для Windows).

```bash
python gui.py                         # графическая оболочка
python main.py                        # консольный прогон обеих программ
python main.py programs/max.asm --stages   # с выводом каждой стадии
python -m unittest discover -s tests  # автотесты
```

## Файлы

| Файл | Назначение |
|---|---|
| `isa.py` | система команд: размерности, коды операций, типы адресации, кодирование/декодирование, дизассемблер |
| `assembler.py` | двухпроходный ассемблер (метки, секции `.data`/`.code`, директива `.word`) |
| `cpu.py` | модель процессора: регистры, память команд и данных, 5 стадий IF-ID-EX-MEM-WB, журнал изменений |
| `main.py` | консольный режим: листинг машинных кодов и трасса выполнения |
| `gui.py` | графическая оболочка на tkinter |
| `programs/max.asm` | задание 1 - поиск максимума в массиве |
| `programs/conv.asm` | задание 2 - свертка двух массивов (длинная арифметика, результат 48 бит) |
| `tests/test_emulator.py` | автотесты (кодирование, флаги, обе программы на случайных данных) |
| `report/` | отчет (`Отчет_РПАОИАС_вариант15.docx`), снимки экрана и результаты прогона |

## Кратко о процессоре

* Команда 32 бита: `OPC(6) | MODE(2) | RA(4) | RB(4) | OP3(16)`.
* MODE - тип адресации OP3: `00` регистровая `R5`, `01` непосредственная `25`,
  `10` прямая `[25]`, `11` косвенно-регистровая `[R5]`.
* 16 регистров общего назначения по 16 бит, флаги ZF, SF, CF, PC 8 бит, IR 32 бита.
* Память команд 256 x 32 бита, память данных 1024 x 16 бит (раздельные - гарвардская архитектура).
* По принципу RISC с памятью данных работает только `MOV`, АЛУ - только регистры и константы.
* Команды: `NOP, MOV, ADD, ADC, SUB, SBB, MUL, MULH, CMP, JMP, JZ, JNZ, JC, JNC, HLT`.
